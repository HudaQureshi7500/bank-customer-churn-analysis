# Bank Customer Churn Analysis | Power BI

## Project Overview

This project explores customer churn and retention patterns using an interactive Power BI dashboard. It demonstrates how data transformation, data modelling, DAX measures, and interactive visualisations can be used to analyse customer data and monitor key business performance indicators.

## Project Objectives

- Analyse customer churn and retention patterns.
- Monitor key customer performance indicators.
- Compare customer segments using interactive filters.
- Explore trends across yearly, quarterly, and year-to-date periods.
- Practise translating customer data into meaningful business insights.

## Tools & Technologies

- **Power BI:** Dashboard development and data visualisation
- **Power Query:** Data cleaning and transformation
- **DAX:** KPI measures and Time Intelligence calculations
- **Data Modelling:** Structuring relationships between data tables

## Key Features

- Interactive dashboard with customer-related KPIs.
- Customer churn and retention analysis.
- Segment-level data exploration.
- Year-to-date (YTD), quarterly, and year-over-year analysis.
- Interactive filters for comparing customer segments.

## Files Included

- `Bankchurn.pbix` – Power BI dashboard project file.

## How to View the Project

1. Download the `Bankchurn.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard and interact with the available filters and visualisations.
